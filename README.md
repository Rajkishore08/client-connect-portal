## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18.x or higher)
- **npm** (v9.x or higher)

### Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/Rajkishores/client-connect-portal.git
cd client-connect-portal

# 2. Install dependencies
npm install

# 3. Environment Variables Setup
# Create a .env file in the root directory:
VITE_SUPABASE_URL=https://bpldaxxwbbcdgsbjbaki.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_neWJgg-i95e6JSxp_1UMzw_h3jNk3Ga

# 4. Start local development server
npm run dev
```

The application will be accessible at `http://localhost:3000` (or `http://localhost:5173`).
