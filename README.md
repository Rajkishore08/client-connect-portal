# One World Solutions — Client Intake & Services Portal

Enterprise Client Intake & Services Management Portal built with React 19, TanStack Start, TanStack Router, TailwindCSS v4, Vite, and TypeScript.

## Features

- **Guided Service Selection**: Streamlined 2-level category and service intake flow.
- **Passport & Visa Services**: Comprehensive preparation, checklist management, and document guidance.
- **Digital Marketing & Web Development**: High-conversion landing pages, SaaS platforms, and enterprise solutions intake.
- **Application Tracking**: Real-time status tracking via unique reference IDs.
- **Consultation Scheduler**: Built-in consultation booking flow with automated slot selection.
- **Admin Dashboard**: Lead management, document inspection, tracking updates, and service catalog management.
- **AI Assistant**: Context-aware assistant for instant client guidance.

## Architecture & Tech Stack

- **Framework**: React 19 + TanStack Start (SSR/Vite)
- **Routing**: TanStack Router (File-based routing)
- **Styling**: TailwindCSS v4 + Radix UI primitives + Lucide Icons
- **State & Data**: TanStack Query + TypeScript Typed Data Layer
- **Build System**: Vite + Nitro engine

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm / bun / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Rajkishore08/client-connect-portal.git
cd client-connect-portal

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Scripts

- `npm run dev` - Launch Vite development server
- `npm run build` - Build production bundle with Nitro engine
- `npm run lint` - Run ESLint checks
- `npm run format` - Format codebase with Prettier
