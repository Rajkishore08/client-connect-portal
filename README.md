# One World Solutions — Global Client Portal & Services Platform

An ultra-premium, high-performance Client Intake & Enterprise Management Platform engineered with **React 19**, **Three.js**, **TanStack Start**, **TanStack Router**, **TailwindCSS v4**, **Vite**, and **Supabase**.

![One World Solutions Platform](https://client-connect-portal-psi.vercel.app/logo-rect.webp)

---

## 🌟 Key Features & Architecture Highlights

- **3D Interactive Holographic Globe Hero**: Built with `@react-three/fiber` and `@react-three/drei`, featuring rotating wireframe longitude/latitude nodes, global city target markers (Chicago HQ, London, Mumbai), and glowing particle clouds.
- **Ultra-Translucent Glassmorphism Interface**: Multi-layered backdrop blurs (`backdrop-blur-2xl`), floating glass pill navigation capsule (`fixed top-2 z-[100]`), and high-contrast ambient glow orbs.
- **Universal International Passport & Visa Services**: Comprehensive intake, document verification checklists, and 24-Hour Emergency Rush filing for international passports, e-visas, and dual residency certificates.
- **Enterprise Web & Custom Software Intake**: Guided scoping calculators, API architecture tools, and React 19 / Next.js platform intake forms.
- **High-ROI Digital Marketing & Growth**: Performance-driven Google Ads PPC funnels, local & international technical SEO audits, and conversion tracking.
- **Light-Theme Authentication Portal**: Integrated split-screen `/auth/login` and `/auth/signup` pages supporting Google OAuth, email/password login, and 1-click guest access.
- **Side-by-Side Testimonials Carousel**: Smooth auto-scrolling horizontal review slider with manual touch controls and indicators.
- **Strict Consular Disclaimer & Policies**: Highlighted official disclaimer banners and online intake / appointment-only guidelines.

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18.x or higher)
- **npm** (v9.x or higher)

### Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/Rajkishore08/client-connect-portal.git
cd client-connect-portal

# 2. Install dependencies
npm install

# 3. Environment Variables Setup
# Create a .env file in the root directory:
NEXT_PUBLIC_SUPABASE_URL=https://bpldaxxwbbcdgsbjbaki.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_neWJgg-i95e6JSxp_1UMzw_h3jNk3Ga

# 4. Start local development server
npm run dev
```

The application will be accessible at `http://localhost:3000`.
